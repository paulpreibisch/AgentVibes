## 🆕 안정적인 설치와 완전한 오디오 미리 듣기 (v5.14.0)

npm에 게시되지 않았던 5.13.2의 모든 변경 사항이 함께 포함되어 있습니다.

- **macOS와 Linux에서 설치가 완료됩니다** — 새로 설정한 환경에서 Piper 설치와 음성 다운로드가 올바르게 실행되어, 오랫동안 이어져 온 첫 설치 문제가 해결되었습니다.
- **미리 듣기가 완전한 믹스를 재생합니다** — 음성, 리버브 및 효과, 배경 음악이 함께 재생되어 에이전트의 실제 음성을 그대로 확인할 수 있습니다.
- **업데이트가 사용자의 수정 사항을 보존합니다** — 수정한 훅 스크립트는 파일이 교체되기 전에 타임스탬프가 붙은 백업으로 저장됩니다.
- **명확해진 오디오 출력 대상** — 설정 화면에서 **Local**은 초록색, **Remote**는 빨간색으로 표시됩니다.
- **올바른 미리 듣기 엔진** — 미리 듣기는 선택한 음성 고유의 엔진을 사용하고 이를 알려주며, Windows와 macOS 음성이 원격 미리 듣기에서도 동작합니다.

### v5.13.0 — 당신의 음성을 어디서나

**Windows**나 **Mac**에 내장된 음성을 골라, 여러분이 듣고 있는 곳이라면 어디서나 들으세요 — 에이전트가 다른 컴퓨터에서 실행 중일 때도요. 게다가 소리가 곧 나온다는 것을 항상 알 수 있는 친절한 미리 알림 차임까지.

- **🖥️ 컴퓨터에 내장된 음성을 어디서나** — Windows나 Mac 음성을 골라 여러분의 기기에서 들으세요. 모든 음성이 표시되며, 사용할 수 없는 음성은 분명하게 표시됩니다.
- **🗂️ 모든 음성이 하나의 목록에** — Piper, Kokoro, ElevenLabs, Windows, Mac, Soprano가 한곳에 모여 있어, 보이는 것이 곧 사용할 수 있는 것입니다.
- **🔔 미리 알림 차임** — 음성이나 음악 미리 듣기 직전에 짧은 소리가 울려, 오디오가 곧 나온다는 것을 알 수 있습니다.
- **🆔 스스로를 소개하는 에이전트** — 선택적 자기소개로, 팀에서 누가 말하고 있는지 알 수 있습니다.

## v5.7.6 신기능 — SSH 원격 페이로드 무결성 + 수신기 재작성

**SSH 원격 음악/음성 수정:** 올바른 프로젝트 음악 트랙과 음성이 이제 원격 수신기에 도달합니다 — 이전에는 활성 프로젝트 설정 대신 전역 구성이 사용되었습니다.

**Bash 수신기 재작성:** Linux/Termux `agentvibes-receiver.sh`가 현재 base64 JSON 페이로드 형식을 디코딩하도록 완전히 재작성되었습니다. v5.5 이전의 오래된 위치 인수 형식은 사라졌습니다.

**이중 인트로 없음:** 개성 pretext(예: "Bcs latin dance here")가 SSH 원격을 통해 두 번 말해지지 않습니다. `play-tts.sh`가 텍스트에 추가하며, 수신기는 다시 추가할 별도의 pretext 필드를 받지 않습니다.

**TUI에 SSH 호스트 표시:** 설정 및 음성 탭에 구성된 SSH 원격 호스트 별칭이 표시됩니다.

**보안 수정**과 전송자 → 수신기 전체 왕복을 커버하는 24개의 새로운 BATS 테스트.

## v5.7.0 신기능 — BMAD v6.6 지원 + Windows 워처 자동 재시작

**BMAD v6.6.0:** AgentVibes가 새로운 에이전트 구조 `.claude/skills/*/agents/`를 감지하고, `~/_bmad`에 전역 설치된 BMAD를 올바르게 처리하며, TTS 주입 중에 v6.6+ 플레인 Markdown 에이전트를 오류 대신 정상적으로 건너뜁니다. BMAD 탭이 전역 설치에서 검출을 올바르게 표시합니다.

**Windows 워처:** `tts-watcher.ps1`은 이제 `~/.agentvibes/tts-watcher.ps1`의 독립 실행형 파일입니다. `npx agentvibes update` 실행 시 최신 워처를 복사**하고** 자동으로 재시작합니다 — 파일과 프로세스 모두 한 번에 업데이트되며 수동 재시작이 필요하지 않습니다.

**Windows 공급자:** `play-tts.ps1`은 이제 원격 오디오를 수신할 때 Linux 서버 구성의 `ProviderOverride`를 준수합니다.

## v5.6.9 신기능 — NPX 설치에서 리버브 및 배경 음악 무음

**WSL 사용자 분들께:** 설정한 보이스와 관계없이 `en_US-lessac-medium`이 재생되었습니다. 수정됨 — 바이너리 검사 전에 `~/.local/bin`을 `PATH` 앞에 명시적으로 추가하여 비인터랙티브 셸에서도 Piper를 찾을 수 있습니다.

**프로젝트별 라우팅:** 세션 시작 훅이 이제 `--project-dir`을 모든 주입된 TTS 명령에 굽습니다. 따라서 `CLAUDE_PROJECT_DIR`이 환경에 없어도 Bash 도구 호출에서 설정된 보이스와 음악이 올바르게 재생됩니다.

`play-tts-piper.sh`와 `play-tts-piper.ps1`이 이제 `agentvibes install`의 크리티컬 훅 배포에 포함되어 업데이트된 버전이 자동으로 반영됩니다.

## 🌟 v5.6.6 신기능 — WSL에서 미리 듣기 버튼 동작 + 포괄적인 Windows 테스트 스위트

**LLM 오디오 설정의 미리 듣기 버튼이 이제 WSL에서 올바르게 작동합니다.** 각 LLM의 보이스, 리버브, 배경 트랙을 설정할 때 미리 듣기를 클릭하면 실제 세션과 동일하게 보이스, 음악, 이펙트를 포함한 전체 오디오 설정이 재생됩니다. 이전에는 `npm link` 및 글로벌 설치 환경에서 배경 음악이 무음으로 처리되었습니다.

**포괄적인 Windows 테스트 스위트**가 CI에 추가되어 기존 Linux BATS 스위트와 함께 실행됩니다. Windows 전용 오디오 경로가 모든 푸시마다 검증되므로 회귀가 조용히 통과되는 일이 없어집니다.

## 🌟 v5.6.4 신기능 — 제거 기능의 심각한 보안 수정

`uninstall --global`이 `~/.claude/` 디렉토리 전체를 삭제하고 있었습니다 — 설정, CLAUDE.md, 스킬, MCP 구성, 모든 것이 사라졌습니다. 수정됨: AgentVibes는 이제 정밀한 제거를 수행하며, 자신이 생성한 파일만 건드립니다. CI의 회귀 테스트가 이를 앞으로 강제합니다 — 문제가 다시 발생하면 배포 전에 빌드가 실패합니다.

## v5.6.3 — Hermes + 더 쉬워진 원격 설정

AgentVibes가 이제 **[Hermes Agent](https://github.com/NousResearch/hermes-agent)** — 자체 호스팅, 자기 개선 AI 어시스턴트를 위해 말할 수 있습니다. 프로덕션 준비 완료된 스킬 2개가 `docs/hermes/skills/`에 포함됩니다:

- **`hermes-agentvibes-hook`** — AgentVibes TTS를 통해 모든 Hermes 응답을 자동 음성 출력. `agent:end`에서 실행, Markdown 제거, 속도 제한, 완전한 SSH MITM 보호 제공
- **`agentvibes-target`** — Hermes가 온디맨드로 임의 텍스트를 스피커에 전송하도록 교육. Windows 및 Android 지원

이번 릴리스에도 포함: `play-tts.ps1`의 PS5.1 호환성 수정, 모달/단축키 수정, BMAD 탭이 이제 모든 에이전트 표시.

## v5.5 신기능 — LLM별 오디오 라우팅

**각 LLM에 고유한 보이스, 프리텍스트, 음악을 부여** — Claude Code, Copilot, Codex가 전역 설정을 건드리지 않고도 서로 다른 소리를 낼 수 있습니다.

- `llm:<name>|...|voice|pretext|engine` 행을 `audio-effects.cfg`에 추가
- MCP 서버가 어떤 LLM이 호출하는지 자동 감지하여 `--llm <key>` 전달
- TUI의 **Setup → Default → Configure**에서 설정
