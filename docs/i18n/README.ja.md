## 🌟 v5.6.7 の新機能 — Windows でのプレビューボタン修正

**LLM オーディオ設定のプレビューボタンが Windows で正しく動作するようになりました。** 設定したボイス、リバーブ、バックグラウンドトラックが再生されます — 間違ったボイスが選ばれたり無音になったりすることはなくなりました。

## 🌟 v5.6.6 の新機能 — WSL でのプレビューボタン対応 + 包括的な Windows テストスイート

**LLM オーディオ設定のプレビューボタンが WSL で正しく動作するようになりました。** 各 LLM のボイス、リバーブ、バックグラウンドトラックを設定する際、「プレビュー」をクリックすると、実際のセッション中と同じようにボイス・音楽・エフェクトを含むオーディオ設定全体が再生されます。以前は `npm link` およびグローバルインストール環境でバックグラウンドミュージックが無音になっていました。

**包括的な Windows テストスイート**が CI に追加され、既存の Linux BATS スイートと並行して実行されます。Windows 固有のオーディオパスがすべてのプッシュで検証されるようになり、リグレッションが気づかれずにすり抜けることはなくなります。

## v5.6.4 — アンインストールの重大なセキュリティ修正

`uninstall --global` が `~/.claude/` ディレクトリ全体を削除していました — 設定、CLAUDE.md、スキル、MCP 設定、すべてが消えていました。修正済み: AgentVibes は外科的な削除を実施し、自身が作成したファイルのみを削除するようになりました。CI のリグレッションテストがこれを今後強制します — 問題がリグレッションした場合、公開前にビルドが失敗します。

## v5.6.3 — Hermes + リモートセットアップが簡単に

AgentVibes が **[Hermes Agent](https://github.com/NousResearch/hermes-agent)** のために話せるようになりました — セルフホスト型の自己改善 AI アシスタントです。本番対応のスキルが 2 つ `docs/hermes/skills/` に含まれています：

- **`hermes-agentvibes-hook`** — AgentVibes TTS 経由で Hermes の全レスポンスを自動音声出力。`agent:end` で発火し、Markdown を除去し、レート制限し、完全な SSH MITM 保護を提供
- **`agentvibes-target`** — オンデマンドで任意のテキストをスピーカーに送る方法を Hermes に教える。Windows および Android をサポート

今回のリリースにも含まれる内容：`play-tts.ps1` の PS5.1 互換性修正、モーダル/ホットキーの修正、BMAD タブがすべてのエージェントを表示するように。

## v5.5 — LLM別オーディオルーティング

**各 LLM に独自のボイス、プリテキスト、BGM を設定** — Claude Code、Copilot、Codex をグローバル設定に触れることなく別々のサウンドにできます。

- `llm:<name>|...|voice|pretext|engine` 行を `audio-effects.cfg` に追加する
- MCP サーバーがどの LLM が呼び出しているかを自動検出し、`--llm <key>` を渡す
- TUI の **Setup → Default → Configure** で設定する

また修正済み: 古いグローバル AgentVibes インストールがある状態での Windows **再インストール**時のインストーラークラッシュ（`spinner.info is not a function`）。

## 🎯 NEW IN v5.3.0 — リモートボイスを思いのままに

- **リモートアナウンスを 1 件ずつ個別にカスタマイズ** — コマンドラインで `--voice`、`--pretext`、`--music`、`--volume`、`--effects`、`--speed`、`--provider` を渡すだけで、そのメッセージだけに適用されます。設定ファイルを書き換えて元に戻す手間はもう不要。
- **イントロフレーズを必要に応じてスキップ** — `--pretext ""` で単一メッセージのプリテキストを抑制できます。

- **リモートサーバーでのボイスプレビューが正しいデバイスにストリーミング** — スピーカーのないマシンでも、TUI プレビューがローカルオーディオにフォールバックしなくなりました。
- **イントロフレーズの二重発話を解消** — 送信側と受信側の両方にプリテキストが設定されている場合でも二重になりません。
- **BMAD パーティモードのボイス割り当てとエージェント分離に 55 件の新規テスト**。
