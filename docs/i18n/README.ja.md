## 🆕 プレビューがどこで再生されるかがわかる (v5.15.1)

- **すべてのプレビューが再生先を表示します** — 音声と音楽のプレビューが、試聴している行のすぐそこに **(locally)** または **(remotely via SSH)** を表示するようになり、推測することも（ヘッドレスな環境で無音を聞くことも）なくなりました。
- **アプリ全体でプレビューを標準化** — 音声ピッカー（Kokoro、Piper、ElevenLabs、エージェントごとの BMAD）と Music ページがすべて同じインジケーターを表示します。音楽プレビューもプロジェクトのリモートレシーバーに追従するようになりました。
- **すっきりした Agents タブ** — 本物の BMAD エージェントを一覧表示し（スキルの内部ヘルパーではありません）、フォーカス時に自身を再チェックします。**Reset** は `X`（Receiver タブへジャンプしてしまう）から **`Del`** へ移動しました。

### v5.15.0 — Windows でのマルチセッション制御

- **有効化しない限りセッションは沈黙します** — セッションが発話するのは、あなたがオンにしたプロジェクトの中だけです。それ以外は指示もトークンコストも追加しません。
- **`/agent-vibes:mute` が Windows でも機能するようになりました** — これまで Windows では効果がありませんでした。プロジェクト単位のミュートとグローバルミュートの両方が、すべてのプラットフォームで尊重されます。
- **Windows でセッションが自己紹介できます** — `{{session}}` は「Claude on my-app in Windows Terminal」をセッションごとに一度だけ通知します。
- **自己紹介がグローバルインストールにも届きます** — その処理を担うスクリプトは、これまでどのプラットフォームでもアップデーターから配信されていませんでした。
- **グローバルの Windows インストールに関する注意:** このアップデート後、セッションはデフォルトでオフになります — `/agent-vibes:unmute` で有効化してください。

## v5.6.3 — Hermes + リモートセットアップが簡単に

- **セットアップタブを統合** — 4 ステップウィザード（言語 → 依存関係 → TTS エンジン → プロバイダー）が旧インストーラー + LLM タブを置き換え。既存ユーザーはプロバイダーに直接スキップ。
- **プロバイダーごとのオーディオ設定** — 各 LLM に独自のボイス、TTS エンジン、リバーブ、ミュージック、プリテキストを設定モーダルで個別に設定。
- **設定を再設計** — すっきりしたフラットリスト: 言語、TTS エンジン、ボイス、詳細度、オーディオ出力先、設定ストレージ、ウィザード再実行。
- **ボイスピッカーを強化** — 3 カラム表示、スペースバーでプレビュー、スクロール位置を保持。

## 🌟 v4.5 の新機能 — 「あらゆる言語で話す」リリース

### 🌍 多言語 TUI — 9 言語対応

`npx agentvibes` のすべての画面、ボタン、ラベルが完全に翻訳されました：

- **英語、スペイン語、フランス語、ドイツ語、ポルトガル語、日本語、韓国語、中国語（簡体字）、イタリア語**
- 初回起動時に言語を選択 — 最初に言語を選んでから始められます
- 設定の言語サブタブ — 再起動なしでリアルタイムに切り替え可能
- すべてのタブラベル、ボタン、フッターのヒント、ステータスメッセージ、BMAD/Receiverタブが翻訳済み
- 言語ごとの i18n ファイル（`src/i18n/en.js`、`es.js`、`fr.js` など）、英語へのフォールバック付き

### 🪟 Windows セキュリティ強化

- **予測不可能な一時ファイル** — すべての一時ファイル名で `Date.now()` が `randomUUID()` に置き換えられました（JS + PowerShell）
- **シェルインジェクション対策** — `which` 検索で `execSync(..., { shell: true })` が `spawnSync` に置き換えられました
- **スマートな音楽プレーヤー検出** — Windows でハードコードされていた `ffplay` が `detectMp3Player()` に置き換えられました
- **ブール値の修正** — `isWindowsTerminal` が `WT_SESSION` の UUID 文字列ではなく、`true/false` を返すようになりました

### 🎙️ クロスプラットフォーム BMAD Speak

- `bmad-speak.js` — クロスプラットフォームのエントリポイント；Windows では PowerShell へ、Mac/Linux では bash へ自動ルーティング
- `bmad-speak.ps1` — エージェントごとのパーソナリティルーティングを備えたネイティブ Windows BMAD Speak
