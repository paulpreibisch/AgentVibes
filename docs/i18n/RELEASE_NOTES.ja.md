## 🎙️ v5.1.0 — ボイスピッカー刷新 + エージェントモーダルの自動保存

**リリース日:** 2026年4月

### 新機能

- **エージェント編集モーダルの自動保存** — エージェントごとのボイス/パーソナリティ/ミュージック/リバーブ/プリテキストの変更が編集中に自動的に保存されるようになりました。明示的な保存ボタンはなくなり、短い「✓ 保存しました!」トーストが各変更を確認します。キャンセルとデフォルトに戻すは以前と同じように動作します。

- **LibriTTS スピーカーの一意な名前** — 904 人の LibriTTS スピーカーが「Anna」「Anna-2」「Anna-3」… 「Anna-16」と表示されなくなりました。それぞれが 16 個の名前プールから決定論的な姓を取得します: **Anna Bell**、**Anna Carter**、**Anna Davis**、…、**Anna Quinn**。基礎となるボイス ID は変更されないため、既存のユーザー設定は引き続き機能します。

- **ピンク/水色の性別記号** — 女性のボイスはピンク（マゼンタ）の **♀**、男性のボイスは水色（bright-cyan）の **♂**、不明は `—` を表示します。ヘッダーの `Gender` 列はカラーの `♀/♂` に置き換えられ（10 → 4 文字幅）、長い名前のためのスペースができました。メインの Voices タブと 3 つのボイスピッカーモーダル（Setup、Agents、Settings）すべてに適用されています。

- **ボイスピッカーの頭文字クイックジャンプ** — `a`–`z` の任意の文字を押すと、その文字で始まる最初のボイスにジャンプします。予約されたキー（`q`、`j`、`k`、`g`、`h`、`l`）はブロックされ、キャンセル/vi ナビゲーションの意味を保持します。

- **ボイスピッカーのページナビゲーション** — `PgUp`、`PgDn`、`Home`、`End` がすべてのボイスピッカーモーダルで動作するようになりました。

- **3 つの新しいバックグラウンドミュージックトラック** — `Late Night Hip Hop Groove`、`Drifting Down the Hall`（90 年代の雰囲気）、`Midnight Charleston Stomp`（スウィング）。トラック数は 15 から 18 に増えました。

### 改善

- **ボイスピッカーの検索バーを削除** — 頭文字クイックジャンプに置き換えられました。古い検索テキストボックスはナビゲーションキーを飲み込むフォーカスの問題がありました。ジャンプは典型的な「ボイス X を見つける」ユースケースで高速です。

- **トラックリストのソート修正** — 絵文字プレフィックス（例: `🎤 Late Night Hip Hop Groove`）を持つトラックは、絵文字のコードポイントではなく、名前のアルファベット部分でソートされるようになりました。順序は Node/ICU バージョン間で一貫しています。

- **お気に入りホットキーは `*` のみ** — ボイスピッカーとメインの Voices タブでお気に入りをマークするための重複した `f` バインディングを削除しました。`f` は頭文字ジャンプに使えるようになりました（例: Frank や Felix にジャンプ）。`*` マーカーはお気に入りを切り替える正規の方法のままです。

### バグ修正

- **Voices タブの未インストール行が破損しなくなりました** — 未インストールのボイスを選択すると、行の `bright-black-fg` ラッパーに過剰にマッチする regex strip により、Provider 列が視覚的に削除されていました。正確なヒントテキストのみを削除する正確なヒントアンカーに置き換えました。

- **Music + Voices タブの点滅アーティファクトが解消** — リストを高速にスクロールしても `█` カーソルが残ブロックを残さなくなりました。両方のタブが、脆弱な位置ベースのスライサーの代わりに、正確な点滅ストリップヘルパーを使用するようになりました。

- **Setup タブが静かに失敗しなくなりました** — `_renderScreen3` は `setupCompleted` の書き込みブロック全体を 1 つの空の `try/catch {}` でラップしていました。破損したローカル設定ファイルは `config.json.bak` にバックアップされて新しく書き直され、エラーは stderr にログ記録されます — 説明なしで「セットアップを繰り返して動けない」状態はもうありません。

- **ボイスピッカーの `q` キャンセルが動作するようになりました** — 新しい頭文字ジャンプが `q`（および他の vi ナビゲーションキー）を飲み込んでいました。予約キーのブロックリストを追加しました。

- **トラックピッカーの大文字小文字を区別しないソート** — Title Case の名前を持つ新しいトラック（`Late Night Hip Hop Groove.mp3`）が、小文字の `agent_vibes_*` トラックの上にリストの先頭にジャンプしなくなりました。

### ユーザーへの影響

- エージェントのボイスや設定の編集が高速化 — 保存をクリックすることを覚えておく必要なし
- 904 人の LibriTTS スピーカー全員が一意でフレンドリーな名前を持つことで、ボイスピッカーが大幅にすっきり
- カラー記号で性別を一目で確認
- バリエーションのための 3 つの新しいミュージックトラック
- Voices タブと Music タブで点滅/スクロールアーティファクトが解消

## 🚀 v5.0.0 — マルチプロバイダー対応: Claude Code + Copilot + Codex

**リリース日:** 2026年4月

### 新機能

- **VS CodeでのGitHub Copilotサポート** — TUIから直接AgentVibesToGitHub Copilot用にインストール・設定できます。`.vscode/mcp.json`と`.github/copilot-instructions.md`を作成します。

- **VS CodeでのOpenAI Codexサポート** — `.codex/config.toml`、`AGENTS.md`のTTSプロトコル、初期化フックを含むCodexの完全統合。

- **統合セットアップタブ** — 旧来の5画面インストールウィザードと個別のLLMプロバイダータブが単一のセットアップタブに統合されました。初回起動時は4ステップウィザード（言語 → 依存関係 → TTSエンジン → プロバイダー）を表示し、既存ユーザーはプロバイダー画面に直接移動します。

- **プロバイダーごとのオーディオ設定** — 各LLMプロバイダー（Claude Code、Copilot、Codex）が設定モーダルを通じて独自のTTSエンジン、ボイス、リバーブ、BGM、Pretextを持てます。

- **TTSエンジン選択画面** — 新しいウィザードステップがOS対応のエンジンリスト（Piper、Soprano、Windows SAPI、macOS Say）を表示し、未インストールのエンジンにはインストールボタンが付きます。

- **設定タブの刷新** — 5つのサブタブレイアウトがすっきりとしたフラットリストに置き換えられました: インターフェース言語、デフォルトTTSエンジン、デフォルトボイス、詳細度、オーディオ出力先、設定ストレージ、セットアップウィザードの再実行。

### 改善点

- **ボイスピッカーを全面的にアップグレード** — 3列表示（名前、性別、プロバイダー）、スペースバーで合成・再生プレビュー、プレビュー中もスクロール位置を保持。

- **ヒントテキストの残像を修正** — エージェントタブとミュージックタブで行間を移動しても、前の行にゴーストテキストが残らなくなりました。

- **Codexのボイスルーティングを修正** — `AGENTS.md`がCodexに対し、通常の音声には`play-tts`を、BMDAパーティーモード時のみ`bmad-speak`を使用するよう指示するようになりました。

### ユーザーへの影響

- AgentVibesがClaude Code、GitHub Copilot、そしてOpenAI Codexで動作するようになりました
- 合理化されたセットアップ体験 — すべてのプロバイダー管理が1つのタブで完結
- 設定ファイルを編集せずにプロバイダーごとのボイスカスタマイズが可能
- 設定ページが大幅にシンプルで素早くナビゲートできるようになりました

## 🐛 v4.6.8 — 新規インストール時のクラッシュ修正

**リリース日:** 2026年4月

### バグ修正

- **設定タブが新規インストール時にクラッシュしなくなりました** — ボイスが未設定の場合、`parseMultiSpeaker()` が null のボイス ID に対して `.includes()` を呼び出していました。安全なデフォルトオブジェクトを返す null ガードを追加しました。インストールウィザード完了直後にこの問題に遭遇したユーザーからの報告です。

- **macOS の /var シンボリックリンクによるリプレイテストの問題** — macOS で `/var` が `/private/var` へのシンボリックリンクであるため、リプレイパスの比較が失敗していたテストアサーションを修正しました。

- **BMAD ボイスの pretext パース** — `bmad-voices.md` の pretext 行が正しくパースされるようになり、TTS 合成前のマークダウン除去がより徹底的になりました。

### ユーザーへの影響

- 新規ユーザーが新規インストール後に設定に移動してもクラッシュしなくなりました
- macOS でテストスイートが確実にパスするようになりました

## 🐛 v4.5.1 — パッチリリース

### バグ修正

- **音楽タブのプレビュー** — 新しいディレクトリから `npx agentvibes` を実行した際、音楽タブのトラックで
  スペースキーを押すと正しく再生されるようになりました。以前は、現在の作業ディレクトリに `.claude/audio/tracks/`
