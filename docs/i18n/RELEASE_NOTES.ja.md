## 🐛 v4.6.8 — 新規インストール時のクラッシュ修正

**リリース日:** 2026年4月

### バグ修正

- **設定タブが新規インストール時にクラッシュしなくなりました** — ボイスが未設定の場合、`parseMultiSpeaker()` が null のボイス ID に対して `.includes()` を呼び出していました。安全なデフォルトオブジェクトを返す null ガードを追加しました。インストールウィザード完了直後にこの問題に遭遇したユーザーからの報告です。

- **macOS の /var シンボリックリンクによるリプレイテストの問題** — macOS で `/var` が `/private/var` へのシンボリックリンクであるため、リプレイパスの比較が失敗していたテストアサーションを修正しました。

- **BMAD ボイスの pretext パース** — `bmad-voices.md` の pretext 行が正しくパースされるようになり、TTS 合成前のマークダウン除去がより徹底的になりました。

### ユーザーへの影響

- 新規ユーザーが新規インストール後に設定に移動してもクラッシュしなくなりました
- macOS でテストスイートが確実にパスするようになりました

## 🌍 v4.5.0 — 「あらゆる言語で話す」リリース

**リリース日:** 2026年4月

全9言語での完全な多言語 TUI サポート、Windows セキュリティの完全な強化、そしてテストの失敗ゼロを達成。

### 🌍 多言語 TUI — 9 言語対応

`npx agentvibes` TUI のすべての画面、タブ、ボタン、ラベルが完全に翻訳されました：

- **英語、スペイン語、フランス語、ドイツ語、ポルトガル語、日本語、韓国語、中国語（簡体字）、イタリア語**
- 初回起動時の言語選択（インストールウィザードの画面 0）
- 設定の言語サブタブ — 再起動なしでリアルタイムに言語を切り替え
- タブバーのラベル、ボタンテキスト、フッターのヒント、ステータスメッセージがすべて翻訳済み
- BMAD タブと SSH Receiver タブが完全にローカライズ済み
- 言語ごとの i18n ファイル、英語へのフォールバック付き

### 🪟 Windows セキュリティとバグ修正

- **一時ファイル名** — すべての `Date.now()` による一時ファイル名が `randomUUID()` に置き換えられました（予測不可能、一時ファイルのハイジャック防止）
- **シェルインジェクション** — `execSync('which ...', { shell: true })` が `spawnSync` に置き換えられました
- **音楽プレーヤー** — Windows でハードコードされていた `ffplay` が `detectMp3Player()` に置き換えられました
- **ブール値の強制変換** — `isWindowsTerminal` が `WT_SESSION` UUID 文字列を漏洩させる代わりに、正しく `true/false` を返すようになりました

### 🎙️ クロスプラットフォーム BMAD Speak

- `bin/bmad-speak.js` — BMAD エージェントスピーチのクロスプラットフォームエントリポイント
- `.claude/hooks-windows/bmad-speak.ps1` — エージェントごとのパーソナリティルーティングを備えたネイティブ Windows BMAD Speak

### 🧪 テストスイート

- 600 テスト、0 失敗

## 🐛 v4.5.1 — パッチリリース

**リリース日:** 2026年4月

### バグ修正

- **音楽タブのプレビュー** — 新しいディレクトリから `npx agentvibes` を実行した際、音楽タブのトラックで
  スペースキーを押すと正しく再生されるようになりました。以前は、現在の作業ディレクトリに `.claude/audio/tracks/`
  が存在しない場合、トラックリストには組み込みトラックが表示されるものの、スペースキーを押しても何も起きませんでした
  （プレーヤーが存在しないパスに対して起動されていたため）。現在はパッケージに同梱されたトラックディレクトリに
  自動的にフォールバックするようになりました。
