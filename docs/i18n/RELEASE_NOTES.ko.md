## 🐛 v4.6.8 — 신규 설치 시 크래시 수정

**릴리스 날짜:** 2026년 4월

### 버그 수정

- **설정 탭이 신규 설치 시 더 이상 크래시하지 않습니다** — 보이스가 아직 설정되지 않은 경우 `parseMultiSpeaker()`가 null 보이스 ID에 대해 `.includes()`를 호출했습니다. 안전한 기본 객체를 반환하는 null 가드를 추가했습니다. 설치 마법사 완료 직후 이 문제를 겪은 사용자의 보고입니다.

- **macOS /var 심볼릭 링크 리플레이 테스트** — macOS에서 `/var`가 `/private/var`로의 심볼릭 링크여서 리플레이 경로 비교가 실패하던 테스트 어설션을 수정했습니다.

- **BMAD 보이스 pretext 파싱** — `bmad-voices.md`의 pretext 줄이 이제 올바르게 파싱되며, TTS 합성 전 마크다운 제거가 더 철저해졌습니다.

### 사용자 영향

- 신규 사용자가 신규 설치 후 설정으로 이동해도 더 이상 크래시하지 않습니다
- macOS에서 테스트 스위트가 안정적으로 통과합니다

## 🌍 v4.5.0 — "모든 언어로 말하기" 릴리스

**릴리스 날짜:** 2026년 4월

전체 9개 언어에 걸친 완전한 다국어 TUI 지원, 완전한 Windows 보안 강화, 그리고 실패한 테스트 없음.

### 🌍 다국어 TUI — 9개 언어

`npx agentvibes` TUI의 모든 화면, 탭, 버튼, 레이블이 이제 완전히 번역되었습니다:

- **영어, 스페인어, 프랑스어, 독일어, 포르투갈어, 일본어, 한국어, 중국어(간체), 이탈리아어**
- 첫 실행 시 언어 선택 (설치 마법사의 화면 0)
- 설정의 언어 서브탭 — 재시작 없이 실시간으로 언어 전환
- 탭 바 레이블, 버튼 텍스트, 하단 힌트, 상태 메시지 모두 번역됨
- BMAD 탭 및 SSH Receiver 탭 완전 현지화
- 언어별 i18n 파일, 영어 폴백 포함

### 🪟 Windows 보안 및 버그 수정

- **임시 파일 이름** — 모든 `Date.now()` 임시 파일 이름이 `randomUUID()`로 교체됨 (예측 불가능, 임시 파일 하이재킹 방지)
- **셸 인젝션** — `execSync('which ...', { shell: true })`가 `spawnSync`로 교체됨
- **음악 플레이어** — Windows에서 하드코딩된 `ffplay`가 `detectMp3Player()`로 교체됨
- **불리언 강제 변환** — `isWindowsTerminal`이 `WT_SESSION` UUID 문자열을 노출하는 대신 올바르게 `true/false`를 반환함

### 🎙️ 크로스 플랫폼 BMAD Speak

- `bin/bmad-speak.js` — BMAD 에이전트 음성의 크로스 플랫폼 진입점
- `.claude/hooks-windows/bmad-speak.ps1` — 에이전트별 퍼소널리티 라우팅이 포함된 네이티브 Windows BMAD Speak

### 🧪 테스트 스위트

- 600개 테스트, 0개 실패

## 🐛 v4.5.1 — 패치 릴리스

**릴리스 날짜:** 2026년 4월

### 버그 수정

- **음악 탭 미리보기** — 새 디렉토리에서 `npx agentvibes`를 실행할 때 음악 탭의 트랙에서 스페이스바를
  누르면 이제 올바르게 재생됩니다. 이전에는 현재 작업 디렉토리에 `.claude/audio/tracks/`가 존재하지 않으면
  트랙 목록에 내장 트랙이 표시되었지만 스페이스바를 눌러도 아무 일도 일어나지 않았습니다 (플레이어가 존재하지 않는
  경로에 대해 실행되었기 때문). 이제 패키지에 포함된 트랙 디렉토리로 자동으로 폴백합니다.
